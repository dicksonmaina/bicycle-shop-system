# Bicycle Shop Management System

## Stages
1. Database + login/security
2. Dashboard
3. Customers + bicycles
4. Repair/job management
5. Inventory
6. Sales + payments + receipts
7. Staff + suppliers
8. Reports
9. Notifications
10. Testing, backup, security and deployment

## Quickstart
- `python3 -m venv venv`
- `source venv/bin/activate`
- `pip install -r requirements.txt`
- `flask db upgrade`
- `flask run`
